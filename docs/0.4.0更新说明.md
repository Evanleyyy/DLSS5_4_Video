# 0.4.0 更新说明：30 系离线开发版

> 本文记录 0.4.0 独立实验版的交付情况。主项目已在 0.4.1 整合相同能力，当前入口和升级方式见 [README](../README.md)。

日期：2026-09-17。分支：`codex/rtx30-offline`。基于原版 0.3.7。

## 新增功能

- 第一层、第二层分别提供“自动选择”“原版 310.8.0”“310.8.SF-v2”“310.8.SF”四个选项，可单独选择、保存并加入命名参数预设。
- 自动模式根据显卡 CUDA 计算能力选择运行库，30 系优先 SF-v2，40 系使用原版；加载前核对架构记录及 SHA-256。
- 提供“自检此层模型”、独立模型自检脚本与命令行 `--runtime` 参数，可实际生成三帧检查所选版本。
- 每层使用隔离渲染进程；切换版本重新建立会话，进程异常记录日志，主程序退出时回收子进程。
- 导出缓存加入运行库版本与文件哈希，更换模型后重新生成对应帧。
- 深度和光流计算完成后释放对应 PyTorch 模型，再进入 DLSS，减少同时占用的显存。
- 保留原版的图片、视频、双层处理、遮罩、降噪、暂停和音轨导出功能。

## 部署与空间优化

- 新增 `启动30系离线版.bat`、`运行模型自检.bat`、`重定位运行环境.bat`。
- 兼容运行库按版本分目录保存；准备工具只下载两个指定发布附件，不下载完整上游仓库。
- 本分支使用独立程序名称、安装 AppId、默认目录和设置，原版工程继续保留。
- 打包暂存目录改为固定路径，复用当前构建目录，避免每次构建累积数 GiB 的完整运行环境。
- 线上仅同步源码、文档、脚本和测试；模型、专有 DLL、虚拟环境、个人设置、日志及构建产物不纳入 Git。

## 原版保留与切换

[原版 0.3.7 固定源码快照](https://github.com/Evanleyyy/DLSS5_Standalone/tree/b1e2ec7fd64e5de274dd2ad14980598bd6df8c07) 保留完整历史。本次只推送 30 系独立分支，不修改线上 `main` 和原版发布分支。本地原版项目、完整备份及正在使用的安装目录继续保留。

建议在独立目录检出 30 系分支，准备其运行环境。无需修改或覆盖原版 DLL。资源准备和操作步骤见 [README](../README.md)。

测试设备为 RTX 4090 Laptop（16 GB，驱动 596.36）。**30 系仍为实验支持，尚未在 RTX 3060/3070/3080/3090 上实机验收。** 架构记录包含 sm_86 不等于所有驱动、显存和分辨率组合都可用。建议在实际 30 系设备上从单层、小分辨率自检开始。

离线渲染允许较慢的处理速度，单帧仍需符合显存上限。原生宿主和 NVIDIA 运行库仍为上游闭源二进制，本次未重写其内部实现，也未发布新的完整安装包。完整来源与许可说明见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
