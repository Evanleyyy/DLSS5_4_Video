# 0.4.1 更新说明

日期：2026-09-17。

## 统一工程与 30 系模型选择

将 30 系分支的能力并入原项目，沿用“DLSS5 本地超分工作台”的启动入口、安装 AppId 和默认目录。第一层、第二层均可分别选择自动、原版、SF-v2 或 SF，并保存到参数预设。30 系自动优先 SF-v2，40 系保留原版行为；旧参数预设自动补全模型选项。

原版 0.3.7 固定源码快照、完整 Git 历史、独立 0.4.0 分支和本地安装包保留。旧独立工程的未提交差异集中归档到 `source-history/rtx30-0.4.0`；经用户批准，已删除原项目完整备份和重复的独立工程，统一在当前目录开发。已有安装目录未被本次源码整理替换。

## 颜色、遮罩与确认处理

- 增加 0～100% 原色彩保留，恢复素材颜色和大范围明暗，同时保留模型处理的细纹理。
- 单图遮罩可控制完整结果或仅控制颜色保留，支持反向保护与羽化。
- 图片、视频和批量处理均需点击“确认参数并开始处理”；导入、调整滑块、切换预设和播放不会触发推理。
- 仅修改颜色或遮罩时复用已确认的 DLSS 结果，导出使用已确认的参数与缓存。

## 处理速度

修复模型退出时的额外等待、相同参数的视频重复计算，以及关闭的降噪和超分参数使缓存失效的问题。同一图片的深度结果可在颜色与遮罩调整时复用。RTX 4090 Laptop 上的具体耗时、启用条件和限制见[处理性能排查说明](处理性能排查说明.md)。

## 安装包旁的模型自动识别

完整安装包和更新包都会检查安装包所在目录的模型，支持 `models`、`sr-models`、`runtime/sr-models` 等布局。先复用安装目录中的相同文件，再将校验通过的本地文件复制到安装目录。原模型保留，缺失或损坏时提示对应组件及下载大小，点击下载后才联网。

升级时，之前配置的模型根目录也作为本地来源；有效文件迁入安装目录后统一使用，其他参数和预设保留。静默安装只进行本地检查和复制，不自动下载。目录示例和日志位置见[安装包同目录模型识别说明](安装包同目录模型识别说明.md)。

## 安装兼容与交付

统一版可升级原项目的完整安装。独立 0.4.0 版仍使用单独 AppId，其已登记目录受保护；更新包拒绝安装到缺少基础运行库的位置。构建产物为 `output/DLSS5_Setup_0.4.1.exe` 与分卷，以及 `output/DLSS5_Update_0.4.1.exe`，并提供 SHA-256 清单。模型权重不嵌入安装包，Git 仓库不上传模型、DLL 或本机设置。

0.4.1 安装文件仅在本地交付，尚未作为 GitHub Release 附件发布。

## 验证范围

当前 120 项回归测试通过。安装模型窗口使用隔离目录和小型校验文件验证本地自动复制、相同文件跳过、缺失提示、必须点击才下载，以及静默离线处理；安装程序包含同一套 `--verify-installer-models` 自检。

三个 DLSS 运行库已完成带音轨视频导出、同会话切换、两层不同模型和界面设置检查。实际验证设备为 RTX 4090 Laptop（16 GB，驱动 596.36）。30 系仍属实验支持，尚未在实际 3060/3070/3080/3090 上验收。
