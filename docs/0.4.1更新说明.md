# 0.4.1 更新说明：30 系能力并入原项目

日期：2026-09-17。

## 统一工程

将 `codex/rtx30-offline` 的能力合并回原项目，继续使用“DLSS5 本地超分工作台”和原来的启动入口、安装 AppId、默认目录及设置路径。旧版用户无需切换到另一套工程，已有模型和参数预设继续使用。

原版 0.3.7 固定快照、完整 Git 历史、独立 0.4.0 分支及其本地安装包保留。本次没有删除原项目完整备份，也没有更新用户正在使用的安装目录。

## 功能

- 自动、原版、SF-v2、SF 四个模型选项，两层分别选择并保存。
- 30 系自动优先 SF-v2；40 系保留原版行为。旧参数预设自动补全模型选项。
- 独立渲染进程、运行库切换重启、SHA-256 和 CUDA 架构校验。
- 模型变化时使旧帧缓存失效；进入 DLSS 前释放深度及光流模型。
- 合并已验证的安装版自检、标准安装不自动下载可选模型及固定构建暂存目录。
- 保留原项目图片、视频、双层、遮罩、降噪、暂停、参数预设和其他超分功能。

## 安装兼容

统一版沿用原项目安装身份，可升级原项目安装目录。独立 0.4.0 版仍使用单独 AppId，其已登记目录受保护。Git 仓库只保存源码、脚本、测试和文档，模型及 DLL 不上传；0.4.1 安装包尚未作为 Release 附件发布。

## 验证

整合后已通过 88 项回归测试，包括旧预设无损加载和 40 系自动选择原版。三个运行库均完成 12 帧视频及音轨导出；同会话切换、两层不同模型、深度与光流显存释放、界面自检及预设重启恢复均通过。

完整安装包与更新包的安装脚本均通过无输出编译检查；Python 模块和 PowerShell 构建脚本语法检查通过。本次验证没有重新安装或替换正在使用的程序。

实际验证设备为 RTX 4090 Laptop（16 GB，驱动 596.36）。30 系仍属实验支持，尚未在实际 3060/3070/3080/3090 上验收。
