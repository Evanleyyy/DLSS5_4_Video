# 0.4.2 更新说明：安装路径选择

日期：2026-09-17。

## 修复内容

完整安装包和更新包均始终显示“选择目标位置”页面，可输入路径或点击“浏览”。检测到旧安装时只将原位置作为默认值，仍由用户确认；“准备安装”页面也显示最终路径。

0.4.1 未指定 `DisableDirPage`，沿用了 Inno Setup 的默认 `auto` 行为：检测到相同 AppId 的已安装程序后跳过路径页。本版显式设置 `DisableDirPage=no`、`UsePreviousAppDir=yes` 和 `AlwaysShowDirOnReadyPage=yes`。

更新包仍要求所选位置已有原项目完整运行库；安装到全新目录请使用完整包。安装包旁的模型识别、校验复制、相同文件跳过和缺失下载提示保持不变。应用功能与 0.4.1 相同。

## 验证

使用实际用户的旧安装登记构建无安装内容的向导探针。旧 `auto` 配置复现路径页被跳过；修复后完整包和更新包在已有安装、首次安装两种情况下均能显示路径页，输入框与浏览按钮可用，修改含中文和空格的目标路径成功。

探针在安装前自动退出，不改写现有程序或安装登记。测试脚本为 `tests/installer_directory_page_smoke.py`，结果位于 `logs/installer-directory-*`。完整包和更新包分别编译并生成 SHA-256 清单。

产物为 `DLSS5_Setup_0.4.2.exe` 与同名分卷，以及 `DLSS5_Update_0.4.2.exe`。完整包必须保留全部分卷并放在同一目录。此前已打开的旧安装向导仍使用旧配置，须运行新包才能使用修复后的向导。

配置依据：[Inno Setup 的 DisableDirPage 文档](https://jrsoftware.org/ishelp/topic_setup_disabledirpage.htm)。
