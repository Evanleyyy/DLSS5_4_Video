# 0.4.4：修改参数后即时渲染

移除所有“确认参数并开始处理”按钮。图片导入、修改模型参数或应用参数预设后自动渲染，继续沿用 0.4.3 的模型驻留与复用。

- 图片：连续参数变化合并约 120 毫秒后计算。预览计算期间滑块仍可操作，当前计算完成后只处理最新设置，不并发加载多份模型，也不显示已经过时的参数结果。
- 遮罩：结束绘制一笔、改变范围或羽化后自动合成；只改 DLSS 颜色与选区时复用模型像素结果。
- 视频：导入、修改参数和拖动进度条后只更新当前帧，不会因一次滑块变化重算整段视频。播放处理视图时，计算较慢会降低预览播放速度，保证界面可操作。
- 导出：视频按当前参数处理完整素材，再导出所选通道；已有完整有效缓存会复用。需要的深度和光流也在导出时自动补齐。单张图片等待最新预览完成后导出。
- 批量图片：选择文件夹后自动开始处理，任务期间固定参数；完成后再修改参数会重新处理该批素材。

当前帧是单帧参考预览，整段导出保留视频时序处理，因此涉及运动和跨帧修复时，两者可能略有不同。启用引导时，只为当前帧计算所需深度与光流，同一帧后续调参会复用引导数据；已有完整引导缓存也可复用。

普通参数变化不重新加载当前模型。原生 DLSS 预设编号、输入尺寸、实际模型版本变化，以及为首次加载的辅助模型腾出显存时，仍可能重建会话。切换引擎或退出软件会释放旧模型。

所有推理仍在本机完成。安装路径选择、安装包旁模型识别、已有相同模型跳过的行为保持不变。
