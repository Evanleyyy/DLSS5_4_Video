# DLSS 原色彩保留

在“参数”页的“DLSS 原色彩保留”区域，用 0～100% 滑块控制原素材颜色的还原程度。功能适用于原版、SF-v2、SF 运行库，单层和双层均可使用，不需要新增模型或下载文件。

## 使用方式

1. 导入素材并选择 DLSS。导入后不会自动计算。
2. 调高“原色彩保留（%）”：0% 使用模型颜色，100% 尽量恢复原素材的局部色彩和大范围明暗。细纹理继续来自模型。
3. 单张图片可切换到“遮罩”页，选择“遮罩作用”，用画笔或矩形绘制范围。
4. 修改参数后自动更新预览，等待完成后再导出；导出不包含红色提示层。参数可另存为预设，应用预设后会自动更新。

调整滑块、遮罩作用、选区或羽化后自动更新，计算期间保留上次完成的预览，红色提示层显示新选区。仅颜色或遮罩变化时可复用已有 DLSS 模型结果；修改模型、两层强度或降噪参数时重新推理。视频调参和拖动进度条更新当前帧预览，导出时处理完整视频。

## 两种遮罩作用

| 作用 | 选区内 | 选区外 |
|---|---|---|
| 整个处理结果 | 使用颜色校正后的 DLSS 结果 | 保留原素材 |
| 仅原色彩保留（DLSS） | 使用颜色校正后的 DLSS 结果 | 保留模型原来的颜色和细节 |

以上按“只处理涂抹区域”说明。“保护涂抹区域”会交换作用范围；羽化让边界渐变。关闭遮罩时颜色校正应用于整张图片。“仅原色彩保留”在强度为 0% 时不会改变模型结果；没有涂抹区域时也不会校正任何位置。

原有局部遮罩只作用于当前单张图片。视频和批量图片使用全画面的颜色保留强度，不使用当前图片的手绘选区。其他超分引擎不使用本功能，其局部遮罩保持原有逻辑。

## 处理与兼容

处理顺序：前置降噪 → DLSS 第一层 → 第二层（可选）→ 后置降噪 → 整体权重 → 原色彩保留 → 单图局部遮罩。颜色参考始终来自未经处理的原素材，两层统一校正一次。整体权重为 0% 时仍保留原图。

算法从原素材与模型结果的差值中提取平滑的局部颜色变化，再按强度加回模型结果。它不会直接把原图纹理叠回，也不会把原图颗粒完整恢复到输出。使用固定的空间滤波，不按各帧统计值自动拉伸；计算分块含边界扩展，避免分块接缝。

100% 表示最大还原强度，不代表每个像素与原素材完全相同。新生成的结构、细小彩色纹理、极暗或高饱和区域仍可能存在差异，超出可表示颜色范围时会截断。当前沿用工程的 8 位 RGB/BGR 流程，不新增 HDR 或 ICC 色彩管理。

旧预设自动补为强度 0%、“整个处理结果”，不重写原预设文件。新的参数进入视频缓存校验，修改强度后会重新生成对应结果。预设保存颜色强度与遮罩作用，手绘选区仍只属于当前图片。
