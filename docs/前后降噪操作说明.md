# DLSS 前后独立降噪

在“参数”分类中，“DLSS 前降噪”和“DLSS 后降噪”分别控制两个阶段，各自具有独立的开关、强度和权重。默认都关闭，保留原来的处理效果。无需下载额外模型。

## 处理顺序

```text
原素材 → 前置降噪 → 第一层 DLSS → 第二层 DLSS（可选）→ 后置降噪 → 整体权重 → 局部遮罩与羽化
```

- **前置降噪**：先清理原素材里的亮度颗粒和色噪，再送入 DLSS。
- **后置降噪**：全部 DLSS 层执行完后统一降噪一次，既适用于单层，也适用于双层。
- 两组参数互不影响；关闭开关会使该组滑块置灰，当前软件会话内保留数值，重新启用即可恢复。

## 参数

| 参数 | 范围 | 初始值 | 作用 |
| --- | --- | --- | --- |
| 启用开关 | 开 / 关 | 关 | 是否使用这个阶段的降噪 |
| 亮度降噪强度 | 0～30 | 3 | 调节明暗颗粒的清理程度 |
| 色彩降噪强度 | 0～30 | 3 | 调节彩色噪点的清理程度 |
| 降噪权重（%） | 0～100 | 100 | 混合该阶段的输入和降噪结果 |

**强度**决定算法处理程度，**权重**决定降噪结果占多少。建议从较低强度开始，放大检查文字、头发、皮肤和细线；强度过高可能抹去真实细节。降噪不能保证修复模型生成的错误结构。

以“后置降噪权重 50%”为例，最终得到一半未降噪的 DLSS 输出，加一半经过后置降噪的 DLSS 输出。它不会直接把原图混入此阶段。

关闭开关、权重为 0%，或亮度与色彩强度同时为 0 时，跳过该阶段，不运行降噪算法。只把一项强度设为 0，另一项仍可工作。

## 整体权重、遮罩与导出

- **整体权重**仍然混合整条处理链的结果和未经处理的原素材。设为 0% 时，跳过两组降噪及全部 DLSS，保留原图。
- 单张图片的局部遮罩和羽化作用于最终结果。默认只处理涂抹区域，选区外保留原图。
- 单张图片、批量图片、视频预览、PNG 导出和 MP4 导出共用同一套设置。导出“DLSS 结果”获得包含降噪、整体权重及适用遮罩的最终效果。
- “原图”通道始终保留原素材；深度和光流依然基于原素材生成。
- 修改任一降噪参数后，旧的 DLSS 结果缓存不再作为当前结果使用，需要重新处理。

## 性能与缓存

使用 OpenCV 彩色非局部均值降噪，匹配窗口为 7、搜索窗口为 21。该滤镜使用 CPU，启用前后两组就会每帧运行两次，图片分辨率及素材内容都会影响耗时。

视频采用逐帧空间降噪，没有跨帧稳定或运动补偿功能。它不能代替时域降噪，也不保证消除闪烁；开启后预览和导出可能变慢。

降噪帧只在内存中处理，不新增降噪中间文件。程序仍使用原有最终 DLSS 帧缓存和手动缓存管理。
