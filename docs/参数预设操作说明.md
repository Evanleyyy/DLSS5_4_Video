# 参数预设

打开“参数”页，顶部为“参数预设”分类。这里保存一整套可反复使用的配置；每层的“模型预设”仍用于选择模型内置的 Preset #1～#3 档位。

## 新增、保存与改名

1. 调整“参数”和“超分”页的设置。
2. 在“自定义名称”输入名称，例如“人像柔和”“夜景降噪”“视频二倍超分”。支持中文、空格，长度为 1～80 个字符。
3. 点击“新增预设”，保存为独立条目。同名预设会提示更名，避免误覆盖。
4. 修改当前预设的参数后，点击“保存预设”覆盖当前条目。直接修改名称再保存，可为当前预设重命名。
5. 需要保留原预设并创建一个变体时，填写新名称后点击“新增预设”。没有选中预设时，“保存预设”也会创建新条目。

“已保存预设”下拉框选择后立即应用整套参数，当前未保存的参数修改会被替换。“应用预设”用于重新载入所选条目的已保存版本。删除前会确认，删除后当前界面的参数保持不变。

## 保存范围

- 两层 DLSS 的所有独立参数、第二层开关、整体权重。
- 前后降噪各自的开关、亮度/色彩强度及权重。
- DLSS 原色彩保留强度，以及遮罩控制整个处理结果或仅控制颜色保留的选项。
- 超分引擎、倍率、分块、种子、颜色校正、PiSA 权重、SeedVR2 批次/卸载参数及模型根目录。
- 关闭的第二层、降噪，以及暂时隐藏的其它模型参数也会保存，再启用时可继续使用。

预设不包含素材路径、视频帧位置、绘制遮罩和导出选项。应用预设后，现有图片遮罩按照保存的“遮罩作用”选项控制整个处理结果或仅控制原色彩保留。应用预设后自动更新图片或当前视频帧；计算过程中保留上次完成的预览，完成后替换为新结果。同一模型的普通参数变化直接复用会话。

处理、生成或导出过程中，预设控件暂时禁用，避免中途更换参数。名称输入框内的空格用于输入文字；其他位置仍沿用空格播放/暂停。

## 持久保存与更新

预设保存在安装目录的 `data/parameter_presets.json`，重启时恢复最后保存或应用的预设。界面出现“已修改”时请点击保存，未保存的修改不会覆盖预设。

保存使用原子替换，并以系统文件锁防止多个窗口同时写入。同名条目、写入失败或文件损坏会显示错误；文件损坏时保留原文件，不会自动重建覆盖。可以备份此 JSON 文件；预设中的自定义模型目录仍需在目标机器存在。

预设数据不属于缓存，软件的手动缓存清理不会清除此文件。更新安装和卸载保留 `data` 目录。

已有 0.3.0～0.3.5 安装版，运行 `output/DLSS5_Update_0.3.6.exe` 并选择原安装目录。全新电脑先安装 0.3.0 基础包及全部数据分卷，再运行本更新包。
