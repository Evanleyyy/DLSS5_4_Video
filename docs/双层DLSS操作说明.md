# 双层 DLSS 与整体权重

在“参数”分类中，可以开启第二层 DLSS，并分别调整两层完整参数。

## 操作顺序

1. 导入图片或视频，打开“参数”分类。
2. 勾选“启用第二层 DLSS”。不勾选时使用第一层。
3. 在“编辑独立参数”中选择“第一层 DLSS”或“第二层 DLSS”。
4. 分别调整各层模型预设、风格、处理强度、局部色调、局部结构、皮肤结构、自动遮罩和界面元素校正。
5. 用“整体权重（%）”调整最终效果与原图的比例。

切换编辑面板不会覆盖另一层的参数；暂时关闭第二层后，其参数仍保留在当前软件会话中。

## 效果顺序

```text
原图 → 前置降噪（可选）→ 第一层 DLSS → 第二层 DLSS（启用时）→ 后置降噪（可选）→ 整体权重 → 局部遮罩与羽化
```

第二层以第一层的结果作为输入，实际再次执行内置 DLSS 模型。两层可以选择不同的预设、风格及参数。

前置、后置降噪各有独立开关、亮度/色彩强度和权重；后置降噪在全部启用层完成后执行一次，详见[前后降噪操作说明](前后降噪操作说明.md)。

整体权重控制完整处理结果与原图的混合比例：

| 整体权重 | 结果 |
| --- | --- |
| 0% | 保留原图，并跳过降噪与模型处理 |
| 35% | 35% 处理结果 + 65% 原图 |
| 100% | 完整使用已启用层的处理结果 |

“处理强度”只控制所在层；“整体权重”控制完整处理链。开启局部遮罩时，再根据选区和羽化将处理结果应用到原图。

## 图片与视频

- 单张图片、批量图片、静态视频、视频处理与导出都应用这套双层设置。
- 单张图片与批量图片保持原尺寸，均使用无视频引导模式。
- 视频中，各层的引导开关、深度约定、水平及垂直运动缩放独立可调。
- 两层共用原视频生成的深度和光流数据。导出时，只要任意启用层需要这些数据，就会按需生成。
- 视频预览前，应生成所需深度和光流，或将两层引导模式都关闭。
- 导出“DLSS 结果”保存整体权重和局部遮罩作用后的最终结果；原图、深度、光流等通道仍按原有勾选项分别导出。

第二层开启后会额外执行一次模型处理，并使用独立处理进程保存自己的视频连续帧状态。两层复用 EXE 内置的运行库，无需额外下载模型。处理结束后释放第二层进程。

## 验证

已用真实 GPU 将双层输出与手动执行两次完整模型处理进行比较，图片和视频连续帧均逐像素一致。验证同时覆盖 0%、35%、60%、100% 权重、两层独立参数、开关切换、局部遮罩 PNG、静态 MP4、批量图片、视频导出及五种窗口尺寸的两套参数面板。
