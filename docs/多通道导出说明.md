# 图片、视频与多通道导出

## 使用步骤

1. 导入图片或视频，打开“导出”分类。
2. 在“输出类型”选择 **图片** 或 **视频**。
3. 在“导出内容”勾选一个或多个通道。
4. 点击“导出所选图片”或“导出所选视频”，选择保存位置。

每次导出都会新建一个独立文件夹。通道分别保存，未勾选的通道不会输出。

## 输出形式

| 输入素材 | 选择图片 | 选择视频 |
|---|---|---|
| 单张图片 | 保存原始尺寸 PNG | 生成静态 MP4，可设置时长和帧率 |
| 视频 | 提取当前帧，或导出全部帧的 PNG 序列 | 按原视频帧率导出完整 MP4，可保留音轨 |

静态视频重复显示当前图片，时长按帧精度取整。MP4 编码要求偶数尺寸，奇数宽高会在右侧或底部补齐一个像素；PNG 保持原始尺寸。

## 可勾选的通道

| 通道 | 内容 | 适用素材 |
|---|---|---|
| 原图 | 原始图片或视频帧 | 图片、视频 |
| DLSS 结果 | 处理结果；单张图片包含已启用的局部遮罩与羽化效果 | 图片、视频 |
| 深度图 | 灰度深度图；PNG 使用 16 位格式，视频为灰度画面 | 图片、视频 |
| 光流可视化 | 用颜色展示运动方向和幅度 | 视频 |
| 局部遮罩 | 羽化后的灰度选区，白色表示涂抹区域 | 图片 |

单张图片没有帧间光流，光流选项会置灰。视频未提供逐帧手绘遮罩，局部遮罩选项会置灰。

缺少的深度、光流或视频 DLSS 会自动生成；未改动的视频深度和光流可以复用有效缓存。单张图片应等待 DLSS 处理完成后，再勾选导出 DLSS 结果。

视频的深度 PNG 来自已有深度缓存，使用 16 位保存不额外增加缓存本身的精度。光流 PNG/MP4 是彩色可视化；原始浮点光流仍保存在视频的 `.flo` 缓存中。

## 文件示例

多通道视频分别保存为：

```text
素材_original.mp4
素材_dlss.mp4
素材_depth.mp4
素材_flow.mp4
```

导出全部帧图片时，每个通道使用单独文件夹，例如：

```text
original/000000.png
original/000001.png
dlss/000000.png
dlss/000001.png
```

缩放、拖动、红色遮罩提示层和对比分隔线不会进入输出。
