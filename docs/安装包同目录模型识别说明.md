# 安装包旁的模型自动识别（0.4.1 起）

完整安装包和更新包均支持此功能。安装器自动传入自身所在目录，安装后的模型窗口会离线检查并复制模型；无须先启动软件或手动填写模型路径。

## 推荐摆放方式

```text
安装包文件夹/
  DLSS5_Setup_0.4.2.exe
  DLSS5_Setup_0.4.2-1.bin
  DLSS5_Setup_0.4.2-2.bin
  DLSS5_Setup_0.4.2-3.bin
  DLSS5_Setup_0.4.2-4.bin
  models/
    guidance/        深度与光流模型
    pisa/            PiSA-SR 及基础模型文件
    seedvr2/         SeedVR2 权重与 VAE
    vosr/            VOSR 权重及配套文件
```

不必备齐所有模型，只放需要使用的部分即可。完整安装包的全部 `.bin` 分卷必须与 `.exe` 放在一起；单文件更新包无需分卷。

`models` 也可以改成 `sr-models` 或 `runtime/sr-models`；还支持将 `guidance`、`pisa`、`seedvr2`、`vosr` 直接放在安装包旁。原有模型目录可以整体复制过来，保留其中的文件名和子目录结构。安装包旁或 `models` 中的单个同名权重文件也会检查，但只有符合内置清单的文件才会使用。程序不会随意接受改名或不兼容的模型版本。

旧版深度模型的 `models/checkpoints`、光流模型的 `torch_home/hub/checkpoints` 以及 `_internal` 内相同结构也可识别。缺失时，可在提示窗口手动选择其他本地模型根目录。

## 安装行为

1. 先检查安装目录已有模型，大小和 SHA-256 一致则跳过，不重写文件。
2. 从安装包旁及上述子目录查找，校验通过后复制到安装目录 `runtime/sr-models`。复制过程中再次校验，完成后才替换目标文件；原位置文件保留。
3. 升级时，之前保存的自定义模型根目录也作为来源；有效文件复制到新位置后，软件统一使用安装目录中的模型。其他参数和预设保留。
4. 缺失或损坏的文件按模型列出数量和下载大小。点击“下载所选缺失模型”后才联网；已有完整文件继续复用。也可点击“稍后下载”，以后在软件内补全。
5. 全部模型齐全时，检查窗口自动关闭，安装继续完成。安装包中的模型组件选项仅决定缺失时默认勾选哪些下载项，不影响本地模型识别。

复制后可以移动或删除安装包及旁边的模型，不影响已安装程序。首次校验大型权重需要一定时间；复制模型也需要安装盘有足够空间。

静默安装只执行本地检查和复制，不弹窗、不下载。结果记录在安装目录 `data/model-installation.json`，日志位于 `data/logs/application.log`。扫描范围限定为安装包所在目录的上述结构及已配置的模型目录，不搜索父目录或整块磁盘。

下载仍使用原有官方来源和固定校验清单，来源与访问限制见[模型按需部署说明](模型按需部署说明.md)。此功能负责识别、复制和提示，不改变模型推理效果或运行库选择。
