# 暂停与继续生成（0.3.1）

在“素材”分类的“生成与处理”中新增“暂停生成”按钮。没有生成或导出任务时按钮置灰；任务开始后可以点击，按钮变为“继续生成”。

## 状态与行为

- **等待当前步骤结束后暂停**：已经收到请求，等待当前 GPU 运算、模型加载步骤或写入操作完成。此时点击“继续生成”可以撤回暂停请求。
- **已暂停**：后台已确认停止推进。进度和已生成结果保留，点击“继续生成”从当前位置继续，不会重新开始。
- 暂停期间仍可调整窗口大小、切换分类和查看日志。素材和处理参数保持锁定，避免同一任务混用不同设置。
- 暂停保留内存、显存和模型时序状态，不会卸载模型；需要释放模型资源时，请等待任务完成。
- 如果在暂停状态关闭软件，会恢复当前任务并等待完成后退出，避免因等待暂停状态而无法关闭。
- 任务完成或失败后按钮恢复为置灰的“暂停生成”，下一次任务不会继承上一次的暂停状态。

## 适用任务

支持单张／批量图片、视频 DLSS、深度、光流、PiSA-SR、SeedVR2、VOSR 及图片／视频导出。深度、光流与视频按帧检查；双层 DLSS 在层之间检查；超分在模型运算边界检查，并在确认前等待已提交的 GPU 运算结束。FFmpeg 导出暂停后停止提交新帧，已提交帧可能仍在编码。

原生 GPU 调用和正在读取的单个模型文件不能强行截断，所以收到请求与真正暂停之间可能有延迟。视频预览工具栏中的“暂停”仍只控制播放，与这里的生成暂停分别工作。

## 更新安装

已有 0.3.0～0.3.4 安装版：运行最新累计更新包 `output/DLSS5_Update_0.3.5.exe`，选择原来的安装目录。更新包复用已安装的运行库和模型，保留用户数据、模型和桌面快捷方式。

新电脑需要先安装 0.3.0 完整离线包及其全部数据分卷，再运行最新累计更新包。更新包会检查基础安装文件；空目录不能直接安装该更新包。
