# 本地超分工作台 0.3.6

“参数”页顶部新增命名预设，可新增、保存、改名、应用与删除；重启恢复最后保存或应用的整套参数。包括双层 DLSS、前后降噪及超分引擎的独立设置，详见[参数预设操作说明](参数预设操作说明.md)。

## 选择模型

在“超分”页选择引擎，导入素材后点击“运行所选引擎”。扩散模型计算较慢，修改参数后由用户点击重新生成；任务结束即退出独立推理进程并释放显存。处理结果预览沿用“DLSS”视图名称，导出勾选“处理结果（所选引擎）”。

生成中可在“素材 → 生成与处理”点击“暂停生成”，等待显示“已暂停”后停止推进；点击“继续生成”从原进度继续。暂停保留模型与显存，具体行为见《暂停生成操作说明》。

| 引擎 | 素材 | 参数与用途 |
|---|---|---|
| DLSS | 图片、视频 | 原尺寸增强；原有双层串联、独立参数与引导功能保持可用 |
| PiSA-SR | 单张、批量图片 | 单步超分；像素修复权重与语义细节权重各为 0～2，默认 1 |
| SeedVR2 3B FP8 | 图片、视频 | 连续帧超分，分批保留上下文；支持 VAE 分块与模型块卸载 |
| VOSR 2.0 1.4B | 单张、批量图片 | 单步视觉超分，分块推理 |

扩散超分可选择 2 倍或 4 倍输出、固定随机种子、分块大小和颜色校正。`wavelet` 恢复低频颜色，`adain` 匹配颜色统计，`nofix` 关闭颜色校正。PiSA 与 VOSR 不用于视频；视频请选择 SeedVR2 或 DLSS。

16 GB 显卡建议先使用 2 倍、256 或 512 像素分块。SeedVR2 默认每批 5 帧、卸载 24 个模型块到内存；增加批次会增加显存占用。超分无法保证真实还原不存在的细节，建议通过对比视图检查文字和人脸。

## 降噪、混合与遮罩

处理链：原图 → 前置降噪 → 所选引擎 → 后置降噪 → 整体权重 → 图片局部遮罩与羽化。前后降噪、整体权重仍在“参数”页。DLSS 的第二层与视频引导仅在选择 DLSS 时参与处理。

超分时先将原图按目标倍率插值放大，再与模型结果混合；整体权重 0% 输出插值放大的原图。遮罩保持原图坐标绘制，羽化后同步缩放到输出尺寸。PNG 结果保留导入图片透明度，MP4 不包含透明度。原图、深度、光流和单独导出的遮罩通道仍保持原素材坐标。

视频用原始帧率导出，支持保留音频。SeedVR2 按连续帧处理并保留跨段上下文，处理结果按帧存入原视频旁的结果缓存。完整且参数匹配的缓存可以直接导出，无需再推理。修改模型、参数或模型文件后，旧结果不可作为当前结果使用。

## 完全本地运行

安装包附带 Python、CUDA 推理库和三套所需权重，不需要安装 Python、ComfyUI 或调用云端接口。模型进程禁用网络连接，缺少文件时明确报错，不会上传素材或联网补下载。

- 默认模型：安装目录下 `runtime/sr-models`。
- 可在“超分”页选择已有模型根目录，其下包含 `pisa`、`seedvr2`、`vosr` 子目录。
- 设置、任务临时文件、任务日志：安装目录下 `data`。
- 视频帧缓存：原视频旁的深度、光流及结果目录。
- “缓存”页可以勾选清理超分临时文件和视频缓存；模型不作为缓存删除。

安装目录推荐选择 F 盘等数据盘。安装版直接使用安装好的运行库，启动时不会再向 C 盘解压整套环境。安装器自身可能使用少量 Windows 临时文件；显卡驱动和操作系统自己的缓存不受本软件控制。

## 安装、升级与卸载

将 `DLSS5_Setup_0.3.0.exe` 与全部同名 `.bin` 数据分卷放在同一目录，运行安装向导。默认完整安装，也可以在自定义安装中取消暂不需要的模型组件。

随后运行 `DLSS5_Update_0.3.6.exe` 更新到带命名参数预设的版本，并保留生成暂停、空格播放及导出缓存修复。已有 0.3.0～0.3.5 的机器直接运行更新包，选择桌面快捷方式实际指向的安装目录即可；无需再次安装模型。

升级选择同一安装目录，安装器覆盖程序文件。卸载移除程序和运行库，保留模型、`data`、原始素材及用户导出结果。需要回收模型空间时，在确认不再使用后自行删除模型目录。

本次提供的是安装包；旧版单 EXE 仍保留用于回退，不包含本版新增超分功能。
