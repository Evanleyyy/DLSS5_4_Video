# 模型按需部署（0.3.7 起）

后续安装包只分发程序、运行库、引擎代码及模型清单，不再内嵌或向本项目 GitHub 发布模型权重。GitHub 旧版含模型的离线安装附件由 0.3.7 安装包替代，本地已安装模型继续保留。

## 安装与使用

1. 0.4.1 完整安装包与更新包会自动检查安装包所在目录的模型。把模型放在旁边的 `models`、`sr-models` 或 `runtime/sr-models` 中，保留引擎子目录；具体结构见[安装包同目录模型识别说明](安装包同目录模型识别说明.md)。
2. 安装后自动离线校验并复制有效文件到安装目录的 `runtime/sr-models`。已有相同文件会跳过，不重写；安装包旁的原文件保留。已保存的自定义模型根目录也作为本地来源，校验通过的文件复制后统一使用安装目录。
3. 缺失或损坏的文件会显示对应模型、文件数量和下载大小，勾选后点击“下载所选缺失模型”才联网。安装向导中的模型组件只预选下载选项；标准安装也会检查所有本地模型。可选择其他本地目录，或点击“稍后下载”完成安装。
4. 静默安装只检查并复制本地模型，缺失情况记入日志，不弹窗也不下载。普通下载中断后可重试，支持服务器允许时的断点续传；`.part` 校验通过后才替换正式文件。应用内首次运行所选引擎、生成深度或光流时仍自动补全需要的文件。
5. “超分 → 本地模型目录 → 检查并补全所选模型”可主动校验和修复。生成前自动检查与此按钮使用同一下载逻辑；软件内下载支持“暂停生成／继续生成”。

默认目录是安装位置下的 `runtime/sr-models`；安装完成后仍可在“超分”页选择其它数据盘。旧安装目录 `_internal` 中的深度、光流模型也会校验并直接复用。不会自动遍历父目录或所有磁盘；其他位置的模型可手动选择根目录。模型、下载进度和校验记录均不会作为生成缓存清理。

模型就绪后，图片与视频推理仍完全在本机运行。只有缺失模型的准备步骤使用网络，不上传素材。

## 下载来源

| 模型 | 来源 |
|---|---|
| PiSA-SR | [作者仓库](https://github.com/csslc/PiSA-SR)提供的 Google Drive 权重 |
| PiSA 的 SD 2.1 基础模型 | [Stability AI 原始仓库](https://huggingface.co/stabilityai/stable-diffusion-2-1-base) |
| SeedVR2 3B FP8、VAE | [SeedVR2 官方插件](https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler)指定的 `numz/SeedVR2_comfyUI` |
| VOSR 及配套文件 | [VOSR 作者仓库](https://github.com/cswry/VOSR)指定的 `CSWRY/VOSR` |
| Depth Anything V2 Large | [Depth Anything 官方仓库](https://github.com/DepthAnything/Depth-Anything-V2)指定的 Hugging Face 权重 |
| RAFT Large | PyTorch 官方 `download.pytorch.org` 权重 |

2026-09-17 实测 SD 2.1 官方文件链接返回 HTTP 401，无法匿名获取。已有完整 PiSA 模型仍能离线使用；缺失时会给出明确错误和来源链接，不会自动切换到第三方镜像或本项目 GitHub 附件。访问权限由上游决定。历史清单中的 `Manojb` 记录仅说明已部署资产的来源，不再用作自动下载地址。

清单固定文件大小与 SHA-256；SeedVR2、VOSR 和深度模型同时固定下载修订版本。SD 2.1 官方地址按原始文件名访问，仍须通过固定哈希验证，不能静默切换模型版本。

## 重新打包

```powershell
# 只检查本机模型，缺失也不阻止构建不含模型的安装包
.\打包安装包.ps1

# 单独准备某套模型：本地优先，缺失从官方源下载
.\.venv\Scripts\python.exe tools/download_sr_assets.py --engine seedvr2

# 检查已有自定义目录，不访问网络
.\.venv\Scripts\python.exe tools/download_sr_assets.py --model-root F:\Models\DLSS5 --check-only --verify
```

`-UpdateOnly` 仍用于运行库没有变化的累计更新。模型、`.part` 文件、安装产物和本机路径配置继续由 `.gitignore` 排除。构建过程不触发模型上传。
