# 0.4.1 模型版本选择与安装

30 系兼容能力已加入原项目，统一使用“DLSS5 本地超分工作台”。原来的 `启动DLSS5.bat`、安装名称、AppId、默认安装目录 `DLSS5Standalone` 和 `data` 设置目录继续沿用。

## 原项目升级

从源码运行时，在原项目准备兼容 DLL 后使用原来的启动脚本。完整安装包携带三个 DLSS 运行库；更新包加入两个兼容库，并复用已安装的原版库及基础依赖。安装到已有原项目目录会保留模型与参数预设。0.4.1 构建产物尚未作为 GitHub Release 附件发布。

独立 0.4.0 30 系版保留自己的工程、分支、AppId 和安装目录 `DLSS5OfflineRTX30`。统一版安装器会拒绝覆盖其已登记目录；请选择原项目安装目录或新的空目录。

## 选择版本

进入“参数”页，在第一层或第二层选择“自动选择”“原版 310.8.0”“310.8.SF-v2”或“310.8.SF”。30 系优先自动或 SF-v2，40 系可继续自动或原版。点击“自检此层模型”执行三帧渲染。旧预设没有模型版本字段时使用自动选择，其他参数保留。

同一层切换运行库会重新创建渲染进程；两层可使用不同版本。相关帧缓存会重新生成，避免混用旧模型输出。

## 资源与离线使用

兼容库保存在 `runtime/dlssnr/`，原版 DLL 保留在原位置。准备工具仅获取两个固定发布附件并核对 SHA-256：

```powershell
.\.venv\Scripts\python.exe tools/prepare_dlss_runtimes.py
.\.venv\Scripts\python.exe tools/prepare_dlss_runtimes.py --check-only
.\.venv\Scripts\python.exe tools/check_dlss_runtime.py --version auto --render
```

源码运行仍需原项目 Python、FFmpeg、原生宿主及依赖。标准安装不自动下载其他模型；PiSA-SR、SeedVR2、VOSR、深度及光流可复用原有模型目录或按需准备。普通 DLSS 渲染无需这些可选模型。

## 验证范围

实机使用 RTX 4090 Laptop，30 系支持仍属实验性质。架构内核包含 sm_86 不等于已经验证所有 30 系显卡、驱动和分辨率组合。首次在 30 系设备上使用时应从 SF-v2、单层、小分辨率自检开始。

安装后的 `DLSS5_App.exe --verify-runtimes "隔离日志目录"` 可验证全部三个运行库、双层处理、模型切换及带音轨导出；30 系上的原版库可能因架构不符被拒绝，一般使用界面自检兼容库即可。
