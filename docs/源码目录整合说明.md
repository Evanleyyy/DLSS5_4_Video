# 源码目录整合

统一主工程为 `DLSS5_Standlone`。原版、30 系兼容、模型选择、原色彩保留、确认后处理和性能修复均在这一套工程中开发。为保持运行和打包路径有效，保留必要的子目录。

| 目录 | 内容 |
|---|---|
| `source/dlss5standaloneV2/` | 当前应用源码与界面 |
| `packaging/` | 当前安装包、独立程序与验证脚本 |
| `tests/` | 自动测试与界面验证 |
| `tools/` | 资源准备和维护工具 |
| `docs/` | 当前使用文档与更新说明 |
| `source-history/rtx30-0.4.0/` | 旧独立版未提交的安装配置、说明、验证脚本及补丁 |
| `original-source/` | 已有的上游原始源码参考 |
| `runtime/` | 本地运行依赖、已获取的第三方引擎与模型 |
| `output/rtx30-0.4.0/` | 已交付的旧 0.4.0 安装包、分卷和说明 |

原备份的 6 个可达 Git 提交、独立版的 8 个可达 Git 提交均已存在于主仓库；没有发现需要另外迁入的独有提交。旧独立版有一个独有的安装验证脚本和未提交的打包修改，已保存到 `source-history` 并逐文件校验。个人设置单独保存在被 Git 忽略的 `data/history/`。

以后从主工程根目录运行 `启动DLSS5.bat`，通过 `打包安装包.ps1` 构建。`DLSS5Standalone` 与 `DLSS5OfflineRTX30` 是已经安装的应用目录，不属于源码备份清理对象。

核对清单和安装包校验记录位于本地 `logs/consolidation/`。
