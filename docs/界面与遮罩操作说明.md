# 界面与遮罩操作

## 功能分类

- **素材**：导入图片、导入视频、批量图片、生成深度、生成光流、运行 DLSS。
- **参数**：第二层开关、整体权重、两层独立的模型预设、风格与强度、自动修正、视频引导和运动缩放。详见[双层 DLSS 操作说明](双层DLSS操作说明.md)。
- **遮罩**：选区作用、绘制工具、画笔大小、羽化、撤销和重做。
- **导出**：保存图片或视频，设置视频质量与音轨。
- **缓存**：统计占用、勾选手动清理、取消待清理任务；详见[缓存管理说明](缓存管理说明.md)。
- **日志**：查看处理过程和错误信息。

宽窗口采用左侧功能面板、右侧预览；窄窗口自动变为上方预览、下方功能面板。分类内部控件自动伸缩、换行，放不下的内容可滚动查看。最小窗口为 680 × 520。

## 视频播放

视频模式下，按空格切换播放／暂停，长按只切换一次。输入框中不触发播放快捷键；空格不控制生成任务的暂停。详见[空格播放操作说明](空格播放操作说明.md)。

## 图片缩放与拖动

1. 在“素材”中导入图片，程序自动生成 DLSS 结果。
2. 在预览图上滚动鼠标滚轮，以指针位置为中心缩放。
3. 左键默认拖动画面；点击“适应窗口”恢复完整图片，点击“原始大小 1:1”按原始像素查看。
4. 使用画笔等工具时，中键或右键仍可拖动画面。
5. “对比”视图左边为原图，右边为处理结果；在“遮罩 → 鼠标左键工具”选择“对比分隔线”可拖动分隔线。

## 局部遮罩与羽化

1. 打开“遮罩”分类，选择“画笔”或“矩形选区”，按住左键绘制。首次落笔自动启用局部遮罩。
2. 默认“只处理涂抹区域”：涂抹位置使用 DLSS 结果，其余位置保留原图。切换到“保护涂抹区域”可反转作用范围。
3. “橡皮”擦除选区；支持全选、反选、清空、撤销和重做。预览区获得焦点时也可按 Ctrl+Z / Ctrl+Y。
4. “画笔直径”和“边缘羽化半径”均以原图像素计量，缩放和拖动不会改变选区位置或实际尺寸。
5. 羽化半径可在 0–100 像素间调整，0 为硬边。绘制时显示即时笔迹，松开后显示羽化效果。羽化调整保留原始选区，可随时恢复硬边。
6. 红色提示层仅标示涂抹区域，可关闭查看实际效果。它不写入导出图片。
7. “保存遮罩 PNG”可保存原图尺寸的灰度遮罩，白色表示涂抹区域，灰色表示羽化过渡。

启用遮罩且选区为空时，“只处理涂抹区域”输出原图；关闭“启用局部遮罩”恢复整图处理。

## 导出与范围

- 在“导出”分类选择“图片”，勾选“DLSS 结果”，点击“导出所选图片”，保存原始尺寸 PNG，包含选区和羽化的实际效果。
- 缩放比例、画面拖动、红色提示层、鼠标光圈和对比分隔线均不影响导出内容。
- 局部遮罩作用于当前单张图片。重新导入素材后重置选区和缩放；批量图片及视频继续按参数面板处理。
- 遮罩通过按选区混合原图与 DLSS 结果实现；调整选区无需重新运行 GPU 推理。
- 导出类型和内容现已分开：类型可选图片或视频，内容支持多个通道打勾。具体用法见同目录“多通道导出说明.md”。
