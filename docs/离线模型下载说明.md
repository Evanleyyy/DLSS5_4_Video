# 本地模型与完整离线包

模型已经随完整安装包上传到 [GitHub Release v0.3.6](https://github.com/Evanleyyy/DLSS5_4_Video/releases/tag/v0.3.6)，以发布附件分卷提供。

## 包含的模型

| 模型 | 用途 | 超分资产体积（十进制） |
|---|---|---:|
| PiSA-SR 及 Stable Diffusion 2.1 基础模型 | 单张和批量图片超分 | 约 5.19 GB |
| SeedVR2 3B FP8 及 VAE | 图片与视频超分 | 约 3.89 GB |
| VOSR 2.0、Qwen VAE 及 DINOv2 | 图片超分 | 约 6.97 GB |

三套超分资产共约 16.06 GB。完整基础安装包约 21.99 GB，还包含 Python、推理运行库、FFmpeg、DLSS 运行文件、深度和光流模型。安装后从软件“超分”页选择引擎。

版本、来源和模型文件 SHA-256 见发布附件及仓库中的 `packaging/sr-assets-manifest.json`。第三方许可说明见 `THIRD_PARTY_NOTICES.md`，各组件按各自上游许可使用。

## 新电脑安装

1. 下载 `DLSS5_Setup_0.3.0.exe`。
2. 下载 `DLSS5_Setup_0.3.0-1.bin` 到 `DLSS5_Setup_0.3.0-11.bin`，共 11 个分卷，保留原文件名并放到安装器旁。
3. 下载 `DLSS5_Setup_0.3.0_SHA256.txt` 并校验。
4. 运行基础安装器。默认包含三套超分模型，自定义安装可选择组件。建议选择数据盘。
5. 下载并运行 `DLSS5_Update_0.3.6.exe`，选择同一个安装目录。更新包也有独立的 `_SHA256.txt`。

`.bin` 是安装器数据分卷，由安装器自动读取。只下载约 4 MB 的基础安装 EXE 无法完成安装。选择安装组件时也应保留整组分卷。

## 已有用户升级

已有 0.3.0～0.3.5 安装版，只需约 35 MB 的 `DLSS5_Update_0.3.6.exe`。升级保留模型与 `data` 下的用户设置、参数预设。

安装后的默认模型目录为 `runtime/sr-models`，可在软件中选择其它已有本地模型根目录。参数预设中的模型路径需要指向本机实际位置。

## 校验下载

在存放下载文件的文件夹打开 PowerShell，执行：

```powershell
$checksums = Get-Content -LiteralPath '.\DLSS5_Setup_0.3.0_SHA256.txt'
foreach ($row in $checksums) {
    $parts = $row -split '\s+', 2
    $downloadName = $parts[1].Trim()
    $downloadHash = (Get-FileHash -LiteralPath $downloadName -Algorithm SHA256).Hash
    if ($downloadHash -ne $parts[0]) { throw "文件校验失败：$downloadName" }
    Write-Output "校验通过：$downloadName"
}
```

更新包可使用相同方法，将校验清单文件名换成 `DLSS5_Update_0.3.6_SHA256.txt`。下载中断时，只需重新下载未完成或校验失败的分卷。

GitHub 的 Source code 压缩包和普通 Git 克隆只包含源码。需要可离线安装的软件与模型时，请下载发布页面的安装附件。
