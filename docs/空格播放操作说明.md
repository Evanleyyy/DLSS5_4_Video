# 空格控制播放与暂停（0.3.4）

导入视频后，按一次空格开始播放，再按一次空格暂停。预览下方的按钮标注为“播放（空格）”和“暂停（空格）”，鼠标点击仍然有效。

- 按住空格只切换一次，松开后再按才能再次切换。
- 数字小键盘锁定（Num Lock）、大写锁定（Caps Lock）和滚动锁定（Scroll Lock）开启或关闭时，空格均可使用；无需关闭这些键。0.3.4 修复了 Windows 下将 Num Lock 误判为 Alt 的问题。
- 鼠标点击普通按钮、勾选项、单选项、滑块或分类标签后，焦点自动回到预览区，不再残留按钮的虚线焦点。普通操作控件不参与 Tab 焦点轮换。
- 只读下拉框选择完成后，可以直接按空格播放／暂停；只读日志区域也支持空格播放。展开的菜单和弹出对话框仍保留自身键盘操作。
- 在可编辑的文本框、数值框、可输入文字的下拉框中，空格保留输入功能；点击普通操作控件离开输入框后，恢复空格播放。
- 即使普通按钮因程序操作获得焦点，空格仍只控制视频预览，避免同时触发该按钮的生成或导出操作。
- 未导入视频、图片模式、生成／导出任务忙碌或正在关闭窗口时，空格不启动播放。
- 空格控制视频预览。生成任务仍通过“素材 → 生成与处理 → 暂停生成／继续生成”控制；空格不会暂停或恢复生成任务。

已有 0.3.0～0.3.4 安装版可以直接运行 `DLSS5_Update_0.3.5.exe` 累计更新。安装时选择桌面快捷方式实际指向的安装目录。运行库、模型和用户设置保持原位。
